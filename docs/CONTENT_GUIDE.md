# Moderneer content guide — March 2026 aligned

## Primary proposition

**Turn signals into decisions you can defend.**

## One-sentence explanation

Moderneer connects fragmented enterprise evidence, assesses what it means, surfaces the decisions that require leadership judgement, and tracks the action that follows.

## Telos description

**Telos Studio is the System of Judgement where assessments, recommendations, decision options and executive considerations are synthesised into a Decision Agenda leaders can challenge, judge and turn into tracked action.**

## Canonical rule

**The question shapes the evidence. The evidence surfaces the decisions. Leadership makes the judgement.**

## Canonical loop

**Frame → Connect → Assess → Trust → Synthesize → Judge → Commit → Learn**

## Correct terminology

Use:
- leadership context
- enquiry / priority / question
- evidence-rich, judgement-poor
- System of Judgement
- operating judgement layer
- assessment
- posture
- Fix Now / Invest / Assure
- decision options
- executive considerations
- Decision Agenda
- decision themes
- executive judgement
- confidence / reliability / integrity
- evidence provenance
- decision readiness
- credible alternatives
- cost of inaction
- reversibility
- commitments
- Transformation Baseline

Avoid:
- "start with the decision"
- "the decision defines the evidence"
- language implying Telos makes the final executive decision
- "any signal can become evidence" as an absolute claim
- "any data, any decision"
- mature competitive-intelligence claims not supported by current implementation
- meeting / communication intelligence as a current production capability
- Decision Evidence Sprint (not the March GTM offer)

## Architecture language

**Systems of record remain the source of truth.**

- Edge acquires and interprets evidence close to source.
- Platform provides configurable models, rules and orchestration.
- Telos provides the leadership workspace for posture, recommendations, decisions and commitments.

## Horizontal positioning

Technology & Transformation is the deepest packaged application today. Telos can use executive considerations across multiple leadership lenses, but cross-functional examples outside the packaged application should be explicitly labelled illustrative.
