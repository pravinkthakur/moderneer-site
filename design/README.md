# Design source

The production CSS is in `assets/css/styles.css`.

This folder contains the source design decisions used by the marketing site:
- `tokens.json` — brand colours, typography and layout tokens
- SVG brand and product artwork lives in `assets/images/`

## Public positioning

- **Moderneer** is the master brand and Outcome Engineering proposition.
- **Telos Studio** is the visible executive decision-intelligence product.
- Internal profiling/orchestration components are deliberately not positioned as separate public products.

## Visual principles

1. High-end enterprise editorial, not generic SaaS.
2. Large typography and deliberate whitespace.
3. Graphite/black foundation with cyan as the primary signal colour.
4. Product visuals should show authentic decision constructs.
5. No stock photography.
6. Motion should explain evidence flow, not decorate the page.
